# AidWise | Web App Preview

AidWise is a first-aid assistance application designed to provide accessible information and step-by-step guidance for common injuries and emergency situations.

This repository contains a sample web-based version of [AidWise](https://github.com/Shiruuukawa/AidWise-First-Aid-Guide-Mobile-Application-), developed for demonstration, testing, and evaluation purposes.

## iPhone Installation

AidWise is available as an installable Web Clip for iPhone testing.

[Download AidWise for iPhone](https://github.com/Shiruuukawa/AidWise-WEB-/releases)

To install:

1. Open the Releases page using Safari on your iPhone.
2. Select the latest available release.
3. Download the `AidWise-iPhone.mobileconfig` file under Assets.
4. Open Settings and select Profile Downloaded.
5. Review the configuration profile and follow the installation instructions.
6. Once installed, AidWise will appear on your Home Screen.

Note: This installation method creates a full-screen web shortcut. It does not install a native iOS application.

## About This Version

This is a sample version of the AidWise application, embedded as a web app for testing purposes only.

The web version provides a preview of the application's interface, navigation, and selected first-aid features. It allows testers to explore the user experience across desktop and mobile devices without installing the complete Flutter application.

Please note the following:

- This is not the final or official release of AidWise.
- Some features, content, and functionality are incomplete or subject to change.
- The web version does not represent the full capabilities of the [original Flutter application](https://github.com/Shiruuukawa/AidWise-First-Aid-Guide-Mobile-Application-).
- First-aid information is provided for demonstration and educational purposes only. Some content has not undergone professional medical review.
- This application should not replace professional medical advice or emergency assistance.
